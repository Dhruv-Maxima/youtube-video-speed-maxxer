# YouTube videos Speed Controller

A simple browser bookmarklet to speed up YouTube and web videos up to 15x.

## How to Install
1. Right-click your browser's Bookmarks Bar and select **Add Page** (or **New Bookmark**).
2. Name it: `Playback Speed`.
3. In the URL/Location box, paste your code or the bookmarklet script.
4. tip*- using this you can even play those unskippable ads in 13x and end them as they didn't appear.
